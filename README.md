## Objetivo do software

Esse projeto tem a finalidade de criar um banco de dados para que salões de beleza possam gerir suas agendas, compras, vendas e serviços próprios do salão.

## Funcionalidades do Sistema

### RF001 – Cadastro de Produto 

Cadastrar cada produto após preenchimento dos campos:
Nome, preço unitário, quantidade, data de validade, categoria, nome do fornecedor e observações.

### RF002 – Cadastro de Fornecedores 

Cadastrar fornecedores de produto após preenchimento dos campos:
Razão social, cnpj, endereço, nome do principal contato para pedidos, telefone para contato, email para correspondência e observações.

### RF003 – Cadastro de Clientes

Requisito responsável por cadastrar os clientes após preenchimento dos campos:
Nome, cpf, data de nascimento, endereço, telefone para contato, constância (classificação em vip ou esporádico) e observações.

### RF004 – Cadastro de Agenda

Cadastrar os serviços oferecidos pelo salão após preenchimento dos campos: 
Nome do serviço, preço, funcionário, horário, cliente e observações.

### RF005 – Cadastro de Funcionários

Cadastrar os funcionários, após preenchimento dos campos:
Nome, cpf, número da carteira de trabalho, data de nascimento, endereço, telefone para contato, cargo, disponibilidade de agenda de trabalho, valor da hora trabalhada por serviço oferecido e observações.

### RF006 – Controle de Estoque

Gerir estoque de produtos, alerta de estoque baixo, vencimento próximo de produtos, após preenchimento dos campos:
Nome do colaborador, nome do produto, quantidade de produtos/itens, horário, nome do cliente que utilizou ou comprou os produtos e observações.

### RF07 – Relatórios

Gerenciamento e análises de gastos, de serviços e produtos, vendas e valores recebidos.
